How Splice works

Splice is a launchpad on Base. Every coin is spliced from composable on-chain mechanics — genes — that live in one immutable Uniswap v4 hook. The hook enforces a constitution no coin can break; each launch then chooses which optional genes to carry.

One hook, not one contract per idea

Most launchpads ship a single fixed mechanic. Splice ships one audited hook that supports every mechanic as a per-coin option. A creator picks genes at launch; the hook reads them and clamps them to constitutional bounds in the swap path. Nothing is upgradeable about the safety core — only which genes a coin turns on.

The constitution — always on

These hold for every coin, regardless of which genes it carries. No gene can switch them off.

The genes — pick per coin

Optional mechanics a launch can splice in. Each is read-only to the hook and bounded by the constitution.

The coin itself

The token is a plain fixed-supply ERC-20: one billion units, minted once, no owner, no mint, no pause, no transfer tax, no blacklist. All market mechanics live in the pool hook, never in the coin. The coin can only enter or leave the pool as part of a swap in its own pool or through Splice’s own contracts — nobody can stand up a shadow market for it, and the launch block only lets the creator’s first buy through so it can’t be sniped.

Fees

The fee gene sets the swap fee, clamped to a hard ceiling. By default it is a flat ~1%, split 60% to the creator, 40% to the platform. A coin can instead carry dynamic or MEV-tax fees, and route part of its fees into a reflexive buyback or to holders as dividends.

Liquidity

Launch liquidity is paired with ETH and minted to a locker. It can never be pulled — only fees are ever collected. There is no bonding curve and no migration step: a coin trades in a real v4 pool from block zero.
