Functions and events

The public surface of the factory, the hook, the router, the token deployer, the coin contracts and the oracle, with signatures from the source.

Signatures below are taken from the source. Functions marked "anyone" have no access control. Amounts in the paired asset are in that token's base units (18 decimals for WHYPE and every listed stock, 6 for USDC).

struct LaunchParams {
  string name;
  string symbol;
  string metadataURI;   // JSON: description, image, website, x, telegram
  address pair;         // zero for HYPE (WHYPE)
  uint256 minPairOut;   // minimum pair amount for the dev-buy conversion
  uint8   capPreset;    // index into capPresets()
  Genes genes;
  StageParam[] stages;  // empty for a Liqio launch
}

struct Genes {
  uint8   feeMode;          // 0 flat (Liqio)
  uint16  feeBps;           // 10..300
  uint16  snipeBps;         // 0, or feeBps+1..3000
  uint32  snipeBlocks;      // 0, or 5..7200
  uint16  buybackShareBps;  // 0, or 1..5000 (with divShareBps at most 8000 together)
  uint16  divShareBps;      // holder rewards, 0..5000
  uint16  maxWalletBps;     // 0, or 50..2000
  uint32  maxWalletSecs;    // 0, or 600..2592000
  uint128 buybackThreshold; // 0, or at least 1000 pair base units
}
Factory events: Launched(token, creator, pair, poolId, pairUsdPrice), DevBought(token, creator, ethIn, pairIn, coinOut) (ethIn is the HYPE sent), HiddenSet(token, hidden), CoinMetadataSet(token, uri), LaunchesPausedSet(paused), FeeRecipientSet(recipient), TokenBlocked(token, blocked), StartCapSet(usd8), CapPresetsSet(usd8[]), CreatorMetadataSet(token, uri), CreatorTransferStarted(token, from, to), CreatorTransferred(token, from, to), CreatorActive(token, creator), TakeoverProposed(token, proposer, newCreator), TakeoverCancelled(token, by), TakeoverExecuted(token, from, to), LauncherSet(launcher, allowed), Collected(token, bps, liquidity, coins, pair, to), ConverterSet(converter), OwnershipRenounced(). Errors: LaunchesPaused, InvalidParams, BadGenes, Blocked, NotAdmin, ZeroAddress, NotCreator, TakeoverClosed.

quoteEthToPair(address pair, bytes route) payablea quote for the HYPE leg: always reverts with QuoteResult(uint256 pairOut); call it with eth_call and decode the revert data
factory(), poolManager(), weth()wiring; weth is WHYPE
Route format: abi.encode(Hop[]) with struct Hop { uint8 dex; address pool; PoolKey key; }. dex is 1 for a Uniswap v2 pair (by pool address), 2 for a Uniswap v3 pool or a v3 fork such as PRJX (by pool address), 3 for a Uniswap v4 pool (by key; a zero currency0 means native HYPE) and 4 for an Algebra pool such as KittenSwap (by pool address). At most four hops. A buy walks the hops from WHYPE to the pair; a sell walks them backwards. The route must start at WHYPE and end at the pair or the call reverts BadRoute. Events: Bought(coin, buyer, ethIn, pairIn, coinOut), Sold(coin, seller, coinIn, pairOut, ethOut), where ethIn and ethOut are HYPE amounts, zero for a trade in the pair itself. Errors: NotListed, Slippage, ZeroAmount, BadRoute, ZeroAddress; QuoteResult(amount) is the result of a quote, not a failure.

The precompile takes abi.encode(uint32 marketIndex) and returns a uint64 with 6 − szDecimals decimals; the oracle scales it to 18 decimals per 1e18 base units, applies the multiplier and, for a wrapped xStock, the wrapper's convertToAssets(1e18) ratio.
