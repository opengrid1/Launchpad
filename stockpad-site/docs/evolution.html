Evolution

A coin can grow into its instincts: pre-committed stages that unlock at market-cap milestones, forward-only and only ever better for holders.

Opt-in. A coin can switch every instinct on at launch, or pre-commit a path that unlocks them in stages as it grows. Either way the path is fixed at launch and can never be changed.
Evolution lets a coin boot guarded and grow into its full instincts. The creator pre-commits an ordered list of stages at launch: a genesis stage live from the first block, then up to five later stages, each with a market-cap milestone and the instincts it switches on. The hook advances the coin through them by itself — no admin, no oracle, no off-chain agent.

​
How a coin advances

1

Pre-commit the path

At launch the creator sets each later stage's market-cap milestone (in USD) and its instincts. The factory freezes each milestone to a pool price and stores the whole path in the hook.
2

Trade toward a milestone

Every buy moves the price, and price times the fixed one-billion supply is the market cap. The hook reads the live pool price on each swap — no oracle, nothing off-chain.
3

Cross it, and evolve

The first swap whose price reaches the next milestone advances the coin to that stage inside the same transaction, switching in its instincts and emitting an event. One large buy can cross several milestones at once.
4

Forward-only

Evolution never runs backward. A later dump lowers the price but the coin keeps the stage it reached, so holders never lose a benefit a milestone already unlocked.

​
Only ever better for holders

Every later stage is checked at launch and can only improve on the one before it. A path that would hurt holders cannot be launched — the factory rejects it. Across any stage advance:

The fee only falls

A later stage's fee is lower or equal, never higher, and the fee engine stays the same.

Rewards only grow

The reflexive-buyback and dividend shares can only rise, and an active buyback's trigger can only get easier — never set out of reach.

Friction only eases

Anti-snipe and the max-wallet cap can only shrink or turn off; they can never be re-armed, lengthened or tightened.

Milestones only rise

Each milestone sits strictly above the start cap and every earlier one, so the path always moves up.
These are enforced by the contract at launch, not promised in copy: the validator proves each stage is holder-favorable before the coin can exist.

​
Deterministic, not an AI model

"Autonomous" here means the coin follows a fixed, public schedule the moment its market cap says so — not a black-box model making calls. No server, no keeper and no admin are in the loop: the trigger is the pool's own price, read on-chain, and the outcome is written in the contract at launch. You can read a coin's whole path and know exactly what unlocks, and when, before you buy.
A coin only evolves if its creator gave it a path at launch; many launch fully formed with no later stages. Check a coin's stages on its page before you trade.
