Functions and events

The public surface of the factory, the hook, the router and the coin contracts, as deployed.

Signatures below are taken from the verified source. Functions marked "anyone" have no access control. Amounts in the paired asset are in that token's base units (18 decimals for ETH and every listed stock).

struct LaunchParams {
  string name;
  string symbol;
  string metadataURI;   // JSON: description, image, website, x, telegram
  address pair;         // zero for ETH (WETH)
  uint256 minPairOut;   // minimum pair amount for the dev-buy conversion
  Genes genes;
  StageParam[] stages;  // empty for a Equo launch
}

struct Genes {
  uint8   feeMode;          // 0 flat (Equo)
  uint16  feeBps;           // 10..300
  uint16  snipeBps;         // 0, or feeBps+1..3000
  uint32  snipeBlocks;      // 0, or 5..7200
  uint16  buybackShareBps;  // 0 for a Equo launch
  uint16  divShareBps;      // holder rewards, 0..5000
  uint16  maxWalletBps;     // 0 for a Equo launch
  uint32  maxWalletSecs;    // 0 for a Equo launch
  uint128 buybackThreshold; // 0 for a Equo launch
}
Factory events: Launched(token, creator, pair, poolId, pairUsdPrice), DevBought(token, creator, ethIn, pairIn, coinOut), HiddenSet(token, hidden), CoinMetadataSet(token, uri), LaunchesPausedSet(paused), FeeRecipientSet(recipient), TokenBlocked(token, blocked), StartCapSet(usd8). Errors: LaunchesPaused, InvalidParams, BadGenes, Blocked, NotAdmin, ZeroAddress.

factory(), poolManager(), weth()wiring
Route format: abi.encode(Hop[]) with struct Hop { uint8 dex; address pool; PoolKey key; }. dex is 1 for a Uniswap v2 pair (by pool address), 2 for a Uniswap v3 pool (by pool address) and 3 for a Uniswap v4 pool (by key; a zero currency0 means native ETH). At most four hops. A buy walks the hops from WETH to the pair; a sell walks them backwards. The route must start at WETH and end at the pair or the call reverts BadRoute. Events: Bought(coin, buyer, ethIn, pairIn, coinOut), Sold(coin, seller, coinIn, pairOut, ethOut). Errors: NotListed, Slippage, ZeroAmount, BadRoute, ZeroAddress.
