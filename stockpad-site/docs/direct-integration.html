Integration

Direct contract integration

Trade a StockPad coin without the site: a direct Uniswap v4 swap with the pool key, or the router with a route; plus prices, launching and claiming from your own code.

Every StockPad coin is an ordinary Uniswap v4 pool. You can swap in it through the PoolManager, through Uniswap's own routers or any aggregator that supports v4, or through the StockPad router, which adds the ETH leg for stock-paired coins. Addresses are on Contract addresses.

​
The pool key

Ask the factory for it, or build it yourself. The coin is always currency0 and the pair currency1. 
PoolKey memory key = factory.poolKeyOf(coin);
// equivalent to
PoolKey({
  currency0:   Currency.wrap(coin),
  currency1:   Currency.wrap(pair),   // WETH for an ETH pair
  fee:         0,
  tickSpacing: 10,
  hooks:       IHooks(0x0bcD3394Dffc047D146E76bCc461d8bEAC9fC0CC)
});
bytes32 poolId = keccak256(abi.encode(key));   // same as factory.listings(coin).poolId
factory.listings(coin) returns the pair and the pool id; listings(coin).createdAt is zero for anything that is not a StockPad coin.

​
Trade through any v4 router

Pass the key to whatever executes v4 swaps for you (the Universal Router, a position manager's swap helper, or your own unlock callback). zeroForOne = false pays the pair and receives coins (a buy); zeroForOne = true pays coins and receives the pair (a sell). The hook needs no hook data. The hook fee is taken from the pair side automatically and shows up as a smaller output or a larger input than the pool math alone would give; quote with that in mind, or use feeBpsNow(coin, isBuy) on the hook. Two rules apply: a buy in the launch block reverts, and sells are never blocked. 
// minimal direct swap inside your IUnlockCallback.unlockCallback
BalanceDelta d = poolManager.swap(
  key,
  SwapParams({
    zeroForOne:        false,                        // buy
    amountSpecified:   -int256(pairIn),              // exact input
    sqrtPriceLimitX96: TickMath.MAX_SQRT_PRICE - 1
  }),
  ""
);
// settle currency1 (the pair) and take currency0 (the coin) as usual

Trade through the StockPad router

The router trades in ETH and handles the conversion to and from a stock. Its buy and sell take a route: empty for an ETH pair, otherwise an ABI-encoded list of hops from WETH to the pair. A sell walks the same route backwards. 
// ETH pair: no route
router.buy{value: 0.1 ether}(coin, "", minCoinOut);

// stock pair, for example TSLAon (USDC pool on Uniswap v3)
// Hop is the router's struct: (uint8 dex, address pool, PoolKey key)
Hop[] memory hops = new Hop[](2);
hops[0] = Hop({dex: 2, pool: 0x88e6A0c2dDD26FEEb64F039a2c41296FcB3f5640, key: emptyKey}); // WETH -> USDC, v3 0.05%
hops[1] = Hop({dex: 2, pool: 0x31227b50eCCDC9C589826AA2D9E7C5619B1895Da, key: emptyKey}); // USDC -> TSLAon, v3
bytes memory route = abi.encode(hops);
router.buy{value: 0.1 ether}(coin, route, minCoinOut);

// stock pair whose USDC pool is on Uniswap v4, for example NVDAon
hops[1] = Hop({dex: 3, pool: address(0), key: PoolKey({
  currency0: Currency.wrap(0x2D1F7226Bd1F780AF6B9A49DCC0aE00E8Df4bDEE),   // NVDAon
  currency1: Currency.wrap(0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48),   // USDC
  fee: 5100, tickSpacing: 51, hooks: IHooks(address(0))
})});

// sell: approve the router first (the coin supports permit)
coin.approve(address(router), amount);
router.sell(coin, amount, route, minEthOut);
The hop list for each stock the site uses is in its configuration file and on Contract addresses. dex 1 is a Uniswap v2 pair, 2 a Uniswap v3 pool, 3 a Uniswap v4 key; at most four hops. Wallets that already hold the pair token can skip the route with buyWithPair(coin, pairIn, minCoinOut) and sellForPair(coin, amountIn, minPairOut). The router holds nothing between calls and always sends the output to msg.sender.

Reading prices

Read slot0 of the pool from the PoolManager and convert: 
// off-chain, with any JSON-RPC client
slot         = keccak256(abi.encodePacked(poolId, uint256(6)))
s0           = poolManager.extsload(slot)                 // bytes32
sqrtPriceX96 = uint256(s0) & ((1 << 160) - 1)
liquidity    = uint256(poolManager.extsload(slot + 3)) & ((1 << 128) - 1)

priceInPair  = (sqrtPriceX96 / 2**96) ** 2              // pair per coin, both 18 decimals
priceUsd     = priceInPair * factory.pairUsdPrice(pair) / 1e18
marketCapUsd = priceUsd * 1_000_000_000
On-chain, use Uniswap's StateLibrary (getSlot0(poolId), getLiquidity(poolId)) or the StateView contract, and FullMath.mulDiv for the square. For a quote, apply the hook fee to the pair side: on an exact-input buy the pool receives pairIn × (1 − fee); on an exact-input sell you receive pairOut × (1 − fee).

Launch from a contract or script

// LaunchParams, Genes and StageParam are the factory's and hook's structs
LaunchParams memory p = LaunchParams({
  name: "Example", symbol: "EXMPL",
  metadataURI: '{"description":"...","image":"data:image/webp;base64,...","website":"https://..."}',
  pair: TSLAon,              // address(0) for ETH
  minPairOut: 0,
  genes: Genes({
    feeMode: 0, feeBps: 100,            // 1% flat
    snipeBps: 2000, snipeBlocks: 150,   // 20% decaying over 150 blocks, or 0 / 0
    buybackShareBps: 0, divShareBps: 2500, // 25% holder rewards, or 0
    maxWalletBps: 0, maxWalletSecs: 0, buybackThreshold: 0
  }),
  stages: new StageParam[](0)
});
(address coin, bytes32 poolId) = factory.launch{value: devBuyEth}(p, salt, route);
route is the same hop list the router uses for that pair (empty for ETH); it is only used when ETH is sent. salt is any value; the token deployer derives the final CREATE2 salt from it. The launch reverts BadGenes for any setting outside the bounds on Limits and validation, and LaunchesPaused or Blocked for operator state.

Claim

hook.payCreator(coin);                 // anyone: pays the creator's share to the creator
hook.pushPlatform(tokens);             // anyone: pays the platform's share to the fee recipient
hook.pushDividends(coin);              // anyone: moves the rewards pot to the coin
coin.claimDividends();                 // holder: claims their share (rewards variant only)
coin.withdrawableDividends(holder);    // view

Testing

Fork Ethereum mainnet at or after block 26,213,781 and call the deployed contracts directly; the verified sources compile with Solidity 0.8.26. For a stock pair your fork needs the routing pools and the oracle to be live, which a mainnet fork provides. For an ETH pair nothing beyond WETH is needed.
