# Umbra site

Landing page for the shielded pool. Plain HTML, hand-written CSS, one small
script. No build step, no framework, no dependencies.

```bash
# open it directly
open index.html

# or serve it
python3 -m http.server 8000   # then visit http://localhost:8000
```

Files:

- `index.html` content and structure
- `styles.css` all styling (warm charcoal, single amber accent)
- `app.js` the anonymity-set slider, the only interactive piece

`umbra` is a placeholder name. The copy is deliberately blunt about the limits
of the design (anonymity set, timing, unaudited setup) rather than selling
around them. Keep it that way if you edit it.
